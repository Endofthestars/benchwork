# Code of Conduct

Benchwork contributors must make technical collaboration safe, respectful, and
evidence-oriented.

## Expected behavior

- Discuss ideas and code without attacking people.
- Treat questions, corrections, and negative results as useful contributions.
- State uncertainty and distinguish evidence from inference.
- Respect privacy, attribution, and research ethics.
- Accept maintainer decisions on scope and safety without harassment.

Harassment, discrimination, threats, doxxing, sexualized conduct, and deliberate
disruption are not tolerated in project spaces.

Report conduct concerns privately to the repository owner through their GitHub
profile. Maintainers may edit or remove content, restrict participation, or ban
contributors when necessary to protect the community.
