# First Rite: Computational Study

`computational-study@0.1.0` is the first versioned Benchwork Rite. It creates a
Working only when its referenced Protocol is `FROZEN` and belongs to the stated
Research Program.

```text
IMPLEMENTATION -> PILOT -> RUN -> ANALYSIS -> REVIEW -> DECISION
```

Each advance records its prior and next stage, a human-supplied reason, and an
Athanor Receipt. The Rite does not yet execute code or calculate results; it
provides the durable lifecycle those later capabilities must bind to.
