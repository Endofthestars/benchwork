# Benchwork 0.3.0rc3 — Repository release verification

`0.3.0rc3` is a GitHub-repository-only release candidate. PyPI publication is
deliberately disabled for this release path.

## Fixed

- The installer now keeps the canonical distribution wheel filename when using
  `uv` or `pipx`, including repair and rollback downloads.
- The release workflow can build, publish the GitHub Pages installer, and run
  its immutable-install smoke test without publishing a Python package index.

## Scope

This candidate retains the Phase 3 contract-only boundary described in the
[0.3.0rc2 release notes](0.3.0rc2.md). It does not add external acceptance,
Chronicle, Storage, Athanor, or package-index authority.
