# Benchwork 0.2.0rc1

`0.2.0rc1` is the M10 "The Seal" Phase 1 acceptance candidate. It is a
prerelease and does not freeze the provisional distribution, CLI, import, or
schema-domain names.

## Integrity

- Chronicle Event and Receipt v1.1 bind all identity and acceptance fields.
- Sequence, chain, Head, migration, and valid-tail recovery fail closed.
- Interrupted v1.0 migration resumes from a verified transaction manifest.
- Deep doctor verifies canonical replay, registries, snapshots, task/output
  blobs, Artifacts, Result exports, project context, and migration state.

## Research contracts

- Task Capsules pin complete Research Snapshots and Capability contracts.
- Capability outputs enforce distinct minimum scientific data contracts.
- Scientific promotion requires explicit Evidence, Claim relation, RQ,
  Protocol, Assessment, and Decision Gates with Actor provenance.
- Working progression follows uniquely bound canonical object lineage.
- Pilot progression requires an explicit, complete Experiment transition.
- Experiment and terminal Run lifecycles preserve failed and excluded outcomes.
- Alembic emits registered deterministic descriptive aggregation with explicit
  comparison and uncertainty methods.
- Student-t numerics are checked against a SciPy CI oracle without adding a
  runtime dependency.

## Operations

- CLI project roots are discovered upward.
- Active Programs are explicit; creation order is never a fallback.
- JSON responses and exit codes form a stable machine interface.
- Governance, compatibility, release, lint, type, schema, link, coverage,
  migration, fault-injection, package, and golden replay checks are CI gates.
