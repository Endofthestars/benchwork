# Benchwork 0.3.0rc2 — The Invitation

`0.3.0rc2` adds the auditable macOS/Linux/WSL installer without changing the
M17 scientific control-plane contracts.

## Added

- POSIX `install.sh` with exact stable/RC/nightly channel contracts
- isolated uv-first and existing-pipx installation
- release-channel, release-manifest, and install-state schemas
- project-independent installation, MCP, plugin, and Host diagnostics
- checksummed, extraction-safe, atomically switched Codex plugin archives
- opt-in Codex plugin/MCP and experimental Claude MCP configuration
- installer-owned repair, rollback, PATH blocks, and uninstall
- release assets, SBOM, provenance, GitHub Pages publication, and installer CI

## Safety

The installer does not require root, mutate system Python, create research
state, install Host CLIs, invoke models, or authorize external Review
disclosure. Checksums are integrity controls rather than release signatures.

## Install

```bash
curl -LsSf https://benchwork.dev/install.sh | sh -s -- --channel rc
```

The stable channel remains unavailable.
