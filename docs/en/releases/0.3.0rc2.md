# Benchwork 0.3.0rc2 — The Invitation

`0.3.0rc2` adds the auditable macOS/Linux/WSL installer and a bounded Phase 3
contract-only implementation slice. The M17 scientific control-plane
contracts are unchanged apart from one additive optional field, recorded under
Fixed below. The Phase 3 additions do not accept or seal an RFC, grant
Chronicle/Storage/Athanor authority, or make a Worker result a scientific fact.

## Added

- POSIX `install.sh` with exact stable/RC/nightly channel contracts
- isolated uv-first and existing-pipx installation
- release-channel, release-manifest, and install-state schemas
- project-independent installation, MCP, plugin, and Host diagnostics
- checksummed, extraction-safe, atomically switched Codex plugin archives
- opt-in Codex plugin/MCP and experimental Claude MCP configuration
- installer-owned repair, rollback, PATH blocks, and uninstall
- release assets, SBOM, provenance, GitHub Pages publication, and installer CI
- 214 published Schemas plus contract tests for the RFC-0011 through RFC-0015
  local validation and replay surfaces
- locally closed Execution Result/Outcome, assurance-Claim, lease-fence,
  Storage Reference Set/provenance-policy/retention-policy, and Patch
  Promotion record invariants; every authority-bearing path without verified
  external facts remains fail closed

## Phase 3 boundary

This prerelease exposes a contract-only local vertical slice, not a complete
Phase 3 runtime or RFC acceptance. Retry scheduling, full Storage replay,
canonical Chronicle absence, Patch MCP application, and the external
authority/resolver inputs they require remain unavailable by design. The exact
evidence and open release work are maintained in the
[Phase 3 exit audit](../PHASE3_EXIT_AUDIT.md) and
[blocker register](../PHASE3_BLOCKER_REGISTER.md).

## Fixed

`benchwork_open_task` minted every Task Capsule for the `codex` Host, so a
non-Codex Tier 1 Host could not record truthful provenance: Athanor correctly
refused the Agent Result with `VALIDATION_REJECTED`. The tool now accepts the
same optional `host_session` argument `benchwork_complete_task` and
`benchwork_fail_task` already took, and mints the Capsule for that Host.

This is an additive optional field under the
[MCP API Policy](../MCP_API_POLICY.md). The 38 frozen tool names are unchanged,
the default remains `codex` so existing clients behave exactly as before, and
an unregistered Host is now refused at the boundary instead of being minted and
later rejected by Ward.

The Claude Code CLI Tier 1 trial that found this is published under
[`examples/phase2-final/host-claude-code`](../../../examples/phase2-final/host-claude-code/README.md).

## Safety

The installer does not require root, mutate system Python, create research
state, install Host CLIs, invoke models, or authorize external Review
disclosure. Checksums are integrity controls rather than release signatures.

## Install

```bash
curl -LsSf https://benchwork.dev/install.sh | sh -s -- --channel rc
```

The stable channel remains unavailable.
