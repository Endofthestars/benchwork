# Benchwork documentation

[English](en/README.md) | [简体中文](zh-CN/README.md)

English is the canonical source for Benchwork documentation. Translations use
the same relative path under their locale directory whenever a localized page
exists.

For the project overview, installation instructions, and CLI quick start, see
the root [English README](../README.md) or
[简体中文 README](../README.zh-CN.md).

| Locale | Status | Documentation |
|---|---|---|
| `en` | Canonical | [English documentation](en/README.md) |
| `zh-CN` | In progress | [简体中文文档](zh-CN/README.md) |

If a page is not available in the selected locale, use the English page. Do not
duplicate an English page into a translation directory solely to fill a gap.

For the repository's localization conventions and contribution workflow, see
[Localization](LOCALIZATION.md).
