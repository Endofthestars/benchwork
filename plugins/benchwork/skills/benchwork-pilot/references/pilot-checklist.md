# Pilot checklist

- Protocol is frozen
- Task Circle matches approved commands, tools, time, and network
- Experiment and arm identifiers match the Protocol
- Every seed and attempt has a planned Run ID
- Failures, cancellations, exclusions, and negative metrics are registered
- Generated artifacts are content-addressed
- Required arms and Runs are complete before transition
- Deviations become Issues or canonical Deviations, not silent edits
